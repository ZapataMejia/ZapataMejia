## What I do

**Release quality.** I decide what can move from staging to production. Every go/no-go is backed by traces, screenshots, and a written Pass / Fail / Blocked — not a green checkbox without proof.

**Automation that survives.** Playwright + TypeScript on Jenkins/Docker; Cypress, Selenium, and Robot Framework when the stack asks for them. I fix the CI that blocks E2E, not only the test that failed.

**Agents in the quality loop.** Herder terminals, LLM consumption, MCP, and TypeSafe decisions so triage and validation scale without turning QA into a chat app.

**Product, not only tests.** At DailyBot I ship the fix: Vue/web, API, chatbot. Outside work I ship client and product web (Astro, React, Next, PWAs).

**Programs from zero.** Ready/done criteria, Linear roles, mandatory evidence, Support ↔ Engineering handoff. At LingoQuesto I took Playwright from near zero to ~56 suites / ~273 tests and ~80% of critical classroom flows in ~3 months.

Talks and workshop support at **QAConf Eje Cafetero** on automation and quality culture in LATAM.
